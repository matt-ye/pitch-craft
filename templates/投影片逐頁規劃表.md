## 規劃表

| 頁 | 標題句（一頁一主張） | 頁面目的 | 視覺類型 | 內容要點（≤3，用「；」分隔） | 講稿段 | 秒 | 備註 |
|---|---|---|---|---|---|---|---|
| 1 | （封面：把一句話主張放上來） | 定錨 | 大字一句 |  | §1 | 15 |  |
| 2 |  |  |  |  | §2 | 0 |  |

欄位說明：

- **標題句**：寫評審看完這頁要帶走的「結論」，不是主題名。「市場」是主題名；「台灣 65 歲以上每 5 人有 1 人需要這項服務」才是標題句。中文 ≤ 24 字、英文 ≤ 14 詞。
- **頁面目的**：定錨／建立痛點／提出方案／給證據／建立可信度／處理反對意見／行動呼籲／備援（Q&A 用，不在正式流程內）。
- **視覺類型**（擇一）：
  - `資料圖：序列` `資料圖：佔比` `資料圖：數字` `資料圖：位置`（資料四類型對應圖表，見 references/04）
  - `圖解：樹狀` `圖解：流程` `圖解：矩陣` `圖解：循環` `圖解：對比`（五種圖解框架）
  - `照片／情境圖`、`大字一句`、`表格`、`示範／影片`、`人物／團隊`
- **內容要點**：這一頁上真正出現的字，最多三點；超過就拆頁或砍掉。
- **講稿段**：對應講稿段落表的 `#`，寫 `§3`；一頁對多段寫 `§3,§4`。
- **秒**：這一頁停留的秒數。全表加總要落在時限的 ±10% 內；備援頁不計。
- **備註**：動畫需求、要補的圖、待查的數字（寫「來源待補」而不是先編一個）。

## 自核（腳本會檢查的項目）

- 頁數 ≤ 上限（備援頁另計）
- 秒數加總在時限 ±10%
- 每頁都有標題句，且長度在門檻內
- 每頁內容要點 ≤ 3
- 每頁視覺類型在選單內
- 講稿段引用的編號在講稿裡存在（給了講稿路徑時才檢查）
- 每一個講稿段至少被一頁引用（沒被引用＝那段講的時候畫面是空的，要確認是刻意的）
