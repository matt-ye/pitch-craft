## 候選結構評分（每項 1–5，總分 30）

| 準則 | 錨定（1 分 ／ 3 分 ／ 5 分） | 結構 A：____ | 結構 B：____ | 結構 C：____ |
|---|---|---|---|---|
| ① 時限吻合 | 段落數在時限內講不完或撐不滿 ／ 勉強 ／ 段落數×每段秒數剛好落在時限 90–95% |  |  |  |
| ② 題目性質吻合 | 結構的段名要硬套才對得上 ／ 大致對 ／ 每段都有話說，沒有空段 |  |  |  |
| ③ 評審決策邏輯 | 評審要結論卻先鋪陳（或相反）／ 部分 ／ 結論先行或鋪陳與評審習慣一致 |  |  |  |
| ④ 必答題覆蓋 | 評分表或必問題有一半以上沒位置放 ／ 需另加段 ／ 每道必答題都有對應段落 |  |  |  |
| ⑤ 素材現況 | 結構要求的證據（結果、數據、市場）你還沒有 ／ 部分有 ／ 素材足以填滿每段 |  |  |  |
| ⑥ 講者負擔 | 段落多到非母語或緊張時記不住 ／ 可練 ／ 段落數與轉場少，一口氣講得完 |  |  |  |
